# Documentation

Documentation is separated by audience and evidence level:

- [`user-guide.md`](user-guide.md) explains installation, catalog use, local
  imports, and Geometry Nodes controls.
- [`development.md`](development.md) explains builds, versioning, tests, CI,
  repository layout, and code-quality gates.
- [`mooble.md`](mooble.md) records the observed Mooble catalog protocol and
  cache behavior.
- [`formats/pmob.md`](formats/pmob.md) records verified PMob binary semantics.
- [`formats/pcontent.md`](formats/pcontent.md) records verified PContent
  container semantics and safety limits.

Contributor scope, architecture, research rules, and the implementation roadmap
remain under [`.agents/`](../.agents/README.md). Those files describe project
decisions; this directory describes behavior and reproducible format evidence.
