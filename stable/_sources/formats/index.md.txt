# Supported format references

These references describe verified traits of the formats currently read by
Mooblender. They distinguish confirmed structure, implementation inference, and
unknown behavior without tying public documentation to individual catalog
products.

```{toctree}
:maxdepth: 1

pmob
pcontent
```

| Extension | Current status | Role |
| --- | --- | --- |
| `.pmob` | Supported for documented records | Recursive geometry and material data |
| `.pcontent` | Supported baseline | ZIP package containing PMob, properties, and images |
